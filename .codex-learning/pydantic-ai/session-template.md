# 学习会话模板

每次继续学习时，可以直接这样对 agent 说：

```text
继续学习 pydantic-ai。请先读取 .codex-learning/pydantic-ai/learning-state.md、
.codex-learning/pydantic-ai/python-ability-table.md 和
.codex-learning/pydantic-ai/roadmap.md，然后按当前阶段继续。
讲源码前先检查我需要的 Python 前置知识，不会的先教。
学完后更新能力表和学习状态。
```

如果新会话的 agent 支持 skills，也可以说：

```text
使用 pydantic-ai-learning-companion，继续学习 pydantic-ai。
```
