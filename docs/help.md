# 获取帮助

如果你需要 Pydantic AI 入门帮助或高级用法帮助，以下资源可能有用。

## Slack

加入 [Pydantic Slack][slack] 中的 `#pydantic-ai` 频道，可以提问、获取帮助，并讨论 Pydantic AI。这里也有 Pydantic、Logfire 和 FastUI 的频道。

如果你使用 [Logfire][logfire] Pro 计划，也可以获得一个与我们协作的专用私有 Slack 频道。

## :simple-github: GitHub Issues

[Pydantic AI GitHub Issues][github-issues] 是提问和向我们反馈的好地方。

[slack]: https://logfire.pydantic.dev/docs/join-slack/
[github-issues]: https://github.com/pydantic/pydantic-ai/issues
[logfire]: https://pydantic.dev/logfire
